# dsh-desktop-shortcut

![DeepSeek Harness Icon](assets/DeepSeek%20Harness.png?raw=true)

**DeepSeek Harness plugin** that creates a Windows desktop shortcut for launching `dsh web`.

**DeepSeek Harness 插件**：在 Windows 桌面自动创建/刷新 `dsh web` 快捷方式。

---

## 🌐 Language / 语言

- [**English**](README.en.md)
- [**简体中文**](README.zh-CN.md)

---

## ✨ Highlights / 特性

- Windows desktop shortcut for `dsh web`
- DeepSeek-style multi-size icon (256 / 128 / 64 / 48 / 32 / 16)
- Auto refresh on every `dsh web` startup
- No third-party runtime dependencies
- Windows only; other platforms skip automatically
